# 常见问题

## 为什么 APK 很小，仍然会下载东西？

APK 不包含完整真题录音和识别模型，只包含应用、资料目录、原文、译文与时间标记。音频按需传输或保存；个人录音首次识别还需下载模型。在线播放也会消耗流量并产生缓存，并非完全免下载。

## 使用真题是否需要识别模型？

不需要。已整理的真题使用预处理原文、单句译文与时间标记。识别模型用于处理不在资料库中的个人录音，可选离线翻译模型也不影响真题库练习。

## 可以完全离线用吗？

完整保存录音后，可离线听这份资料。个人录音在识别模型已下载时可本机识别；默认新增译文仍需网络，除非已下载并选择离线翻译。部分缓存可用不等于完整录音已离线保存。

## 导入为什么慢、为什么发热？

设备需解码、语音识别和定位每个句子，长录音或较弱的设备会耗时较久。正式版固定 2 线程并保留过热等待，但不能消除计算发热。可暂停处理，避免一边充电一边长时间导入；优先使用已处理好的资料库。

## 原文有了，译文还没有？

联网翻译可能被限流、连接失败或暂不可达。已完成的英文和时间标记会保留，稍后在导入进度中继续 / 重试译文。机器识别或翻译本身可能出错，可手工修正。

## 音频播放失败或一直缓冲？

检查当前网络是否能访问 GitHub 音频源，重试或先保存完整录音。跳到未缓存位置需要额外读取音频。2.0 支持失败后重新初始化播放器，但无法保证外部服务持续可用。

## 为什么有些说明或题号不在全文中？

原文资料主要覆盖长对话、短文和讲座。来源未列出的考试说明、报题不进入随机句池，整篇录音仍保留这些内容。

## 换手机或卸载后能恢复记录吗？

目前无账号同步和面向用户的完整备份恢复。学习记录、收藏、导入资料和壁纸保存在本机；直接覆盖升级可以保留，卸载或清除数据会删除。导出的诊断日志不能用于恢复全部记录。

## 安装失败怎么办？

确认 Android 8.0+、ARM64 或 x86_64，文件下载完整且有足够空间。若提示签名冲突，核对已安装应用的来源；不要为排错直接卸载有学习记录的版本。正式版与测试版包名不同，安装测试版不会升级正式版。

## 后台没有播放卡片？

先实际开始播放，再检查通知权限和系统媒体控制区域。Android / 厂商系统可能对后台运行有额外限制，允许应用后台运行。仍异常时，请附手机型号、Android 版本及导出的使用日志反馈。

## 是否收费？是否需要登录？

本仓库提供 2.0 安装包免费下载，应用无需登录，没有内购流程。访问外部服务可能产生网络流量费；免费翻译接口与资源地址的长期可用性不作保证。
