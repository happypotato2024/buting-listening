# 正式版 2.0.0 验证记录

交付文件：不听听力-v2.0.0.apk。包名 cn.tingjian.cet6，versionCode 13，Android 8.0+，ARM64 / x86_64。

## 界面与图标

- 使用常规无衬线字体，统一按钮、设置行、标题的字号和字重，缩小次要控件，移除多余卡片边框。
- 上一句、重听、下一句等宽排列；播放区独立占位，长原文在卡片内滚动；辅助操作位于“更多”。
- 平板宽屏分栏。个人页与偏好设置采用浅灰背景、白色分组卡片和橙色开关。
- 白底橙色“不／听”图标重新调整圆圈比例、间距和字形；APK 内图标与源图解码像素一致。

## Android 11 x86_64 模拟器检查

- 手机 1080×2400 / 480 dpi、较矮手机 720×1280 / 320 dpi、平板尺寸 1920×1200 / 160 dpi 均通过布局断言。每种尺寸检查 20 / 22 / 26 三档原文字号：按钮不换行、原文不覆盖操作区、播放区不遮挡底栏、主播放键至少 44 CSS 像素、页面无横向溢出。
- 个人设置行字重为 400。截图分别保存在 `.qa/v2-phone`、`.qa/v2-short`、`.qa/v2-tablet`。
- 全流程回归通过：首页、签到、壁纸、原生精听、收藏、全文点句整篇播放、暂停拖动保持暂停、随机句及重播与原文身份匹配、后台播放、个人页与 29 组音频库、固定 2 线程。逐项结果见 `.qa/v2/functional-checks.json`。
- 注入播放失败并释放底层播放器后，页面“重试”和通知栏 resume 均成功重新播放；“更多”中的停止按钮可用。见 `.qa/v2/retry-checks.txt`。该测试验证恢复路径，不代表已重现或消除用户截图中的网络失败根因。
- 在原正式版基础上覆盖安装，检查之前保存的收藏、统计、签到、学习目标及壁纸仍然存在；结果见 `.qa/v2/upgrade-checks.txt`。
