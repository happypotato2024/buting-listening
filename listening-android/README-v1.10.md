# 不听听力 Android APK

当前版本1.10.0（versionCode 11），Android 8.0及以上。包名cn.tingjian.cet6与签名沿用旧版，可覆盖安装。最新输出路径与校验值见build/latest-apk.json。设置、签到、旧收藏和精听进度在覆盖安装时保留；卸载或清除应用数据会删除本机记录。

## 本次修正

- 首页Learn/Review高度从94px缩至64px，平板从124px缩至76px，签到卡片同步缩小。首页底栏透明、其他页面底栏半透明，与背景融合。
- 随听使用4507份独立原声单句文件，音频、原文和译文按同一个句子编号绑定。直接从片段开头播放，避免手机长MP3跳转偏差；重听、慢速、循环均复用同一片段。
- 精听继续使用完整录音；退出随听时恢复完整音频，进度与时长分别处理，避免短片段覆盖长录音时长。
- 独立片段增加约207MB；素材由已有录音完整解码后，按声学时间标记精确截取PCM样本生成，避免MP3快速跳转缺失解码历史。tools/prepare-sentence-audio.py生成片段；tools/verify-sentence-audio.py对全部片段与原录音对应位置作解码波形比对。

## 功能

- 白底橙色上下「不/听」图标，名称「不听听力」。首页只保留Learn、Review、签到与壁纸入口；所有主要页面删除口号与重复说明。
- 底栏只有随听/我的；首页Learn继续精听、Review开始收藏复习。真题材料唯一列表入口为我的学习→更换真题。其他页面有返回首页箭头，安卓返回键先关闭弹窗，再回首页。
- 2019—2025年29份真实录音全部离线内置。原1225段双语材料拆成4507句，按实际录音进行声学强制对齐；单句精听、随机抽句、单句停止、再听一遍、循环与慢听直接可用，不要求用户标记内置真题。
- 随听可选择指定一套、当前材料、全部资料或收藏；完整录音保留，可只听或边听边看。自动时间对齐存在少量边界误差，不能视为人工校订。
- 中文沿用原有27份机器参考译文与2份整理参考译文。不能按标点逐句对应的显示完整「所在段译文」，明确标注语境。
- 安卓壁纸按钮调用原生系统相册/文件选择器，读取图片、处理EXIF方向、缩图并保存至应用私有目录；预设与深浅文字使用SharedPreferences保存。通过本地私有图片地址展示，不上传图片。取消和重启保留已有壁纸。浏览器环境保留IndexedDB图片导入路径。
- 我的学习包含目标、实际听力与收藏复习次数、签到日历与收藏。偏好含速度、字号、纯听、自动播放、译文、复习数量和连续随听等，设置立即生效并本机保存。
- 旧收藏段落升级为对应全部句子，阅读位置迁移至所在段第一句；保留实际录音进度。
- 手机与平板横竖屏自适应。宽屏精听控制/阅读分栏，个人页双栏，真题卡片2/3/4列。主要按钮48逻辑像素，设置至少44像素。壁纸与底栏铺满，阅读区保留边距。
- 当前材料可通过系统文件工具导出完整音频及原文译文；个人偏好、签到和其他材料不包含在当前材料备份中。无需登录，没有云同步。

## 资料与配对

来源：Ysoseri1224/CET-6-Listening-10-Years-Resources-and-Analysis，固定版本42fc6658e0b4a3dbae06755ba105d79169820576，CC BY 4.0。应用保留署名、许可和修改说明。

核对实际录音后修正2025年6月与2023年12月两组原始音频编号互换，记录在content/alignment/audio-pairing.json；显示套卷以英文原文编号为准。未修改原始资料，输出记录实际录音来源ID、原文件SHA256与转码文件SHA256。

原始与优化录音在.content/library/originals和encoded中。原录音保留，输出64kbps单声道MP3保留全部内容；构建生成的音频使用同卷硬链接以减少重复占用，构建输入请勿原地编辑。不同卷自动回退复制。

拆句资料及声学标记位于content/alignment。使用facebook/wav2vec2-base-960h的Xenova ONNX导出（固定a19f851b3d42865797e410752b4c570c871e4825）生成CTC时间标记；模型与推理缓存仅在系统临时目录，不进入APK。构建使用已生成资料，不需要模型或联网。

2026年6月仍是外部音频来源，没有配套逐句原文。自导入材料需自带时间标记才能单句播放；内置29份真题已完成。切换应用或锁屏暂停播放。

## 构建与验证

```powershell
node tools/build-apk.mjs
python tools/verify-apk.py
```

BUTING_APK_OUTPUT可指定绝对输出路径。大体积APK中间文件使用系统临时目录，保留已有交付APK。SDK下载压缩包已删除，解压后的构建工具保留可用。

node tools/test-playback.mjs检查29份录音的延迟加载、首/中/末定位、重叠请求、快速切句、范围及页面取消、失败重试与连续播放。node tools/test-refinement.mjs检查首页对齐、两个导航、材料入口、旧记录迁移、浏览器壁纸、原生壁纸协议模拟、单句停止/循环、指定真题随机听句、译文及精听上下文。node tools/test-tablet.mjs检查五种平板尺寸、手机窄屏、翻页与设置可达。python tools/verify-alignment.py逐一检查4507句覆盖、声学时间顺序，并抽查609句与识别词时间一致性。python tools/verify-apk.py检查APK完整性、资源与29份录音SHA256，生成验证报告。

这些检查不替代安卓真机验收。暂无已连接安卓设备，未进行原生相册、私有文件保存、系统WebView播放和安装的真机测试。
