# 不听听力 2.0 使用说明

## 安装与升级

从本仓库 Releases 下载 `.apk`。在手机文件管理器中打开，按 Android 提示允许当前文件管理器 / 浏览器安装应用，再确认安装。

- 支持 Android 8.0+ 的 ARM64 设备；安装包另含 x86_64 模拟器支持，不含 32 位 ARM。
- 旧正式版包名为 `cn.tingjian.cet6`，直接覆盖升级会保留记录、收藏、偏好和壁纸，不要先卸载。
- 独立测试版包名为 `cn.buting.lab`，可与正式版并存，数据不会自动迁移。
- `SHA256SUMS.txt` 用于核对下载完整性；电脑可使用 PowerShell `Get-FileHash .\buting-listening-v2.0.0.apk -Algorithm SHA256` 比对。

## 首页、资料库与学习记录

首页 **Learn** 进入精听，**Review** 复习收藏句子。首页可设置壁纸、签到；「我的」中可查看学习计划、听力时长、收藏和签到日历。

切换录音：在「我的」页面点「更换资料」，或在练习页点「更换资料」。资料库支持查找、练习和下载。完成整篇下载后，可离线播放；下载失败可重试，未完成下载时不保证整篇离线可用。

「我的 → 学习偏好」可调整播放速度、进入精听时是否显示原文、自动播放、译文开关、英文字号、每轮复习数量与首页壁纸。更换资料与修改偏好不会清除学习记录。

## 单句精听

1. 选择一份录音，在练习页选「单句」。
2. 点击橙色播放键；再次点击暂停，再次播放则继续。
3. 用「上一句 / 重听 / 下一句」切换或重复当前句。
4. 点「原文 / 译文」控制显示，先盲听再看答案；星标收藏难句。
5. 调整倍速，或点击循环图标反复听当前句。进度条在当前句的范围内定位。

长句可以在白色原文卡片内上下滚动，底部播放区独立保留。参考译文可能有误，可通过「更多 → 修正这句」修正，或「标记问题」留待反馈。

## 整篇听力与全文点播

切换到「整篇」后，进度条覆盖整份录音。可直接拖动，或用「−5 秒 / +5 秒」调整位置。暂停时拖动仍保持暂停。

点击「全文预览」查看句子列表。整篇模式下点一句，从该句开始继续播放后续录音；单句模式下点一句，只练这一句。线上未缓存的位置需要缓冲。考试说明等未收录进原文的部分，仍可用整篇进度条定位。

## 随听与 Review

底栏「随听」用于碎片时间练习；可选择当前资料、资料库或收藏等抽取范围，点击「随机一句」开始。重听会保持同一条录音和句子，不重新抽取。

首页 Review 从收藏中进行复习，可在学习偏好中调整每轮数量和是否显示译文。收藏为空时，先在精听中为句子加星标。

## 自行导入音频

1. 在练习页点「导入」，阅读提示并通过系统文件选择器选择 MP3、M4A 或 WAV 英语录音。
2. 首次需联网下载约 148 MB 识别模型。匹配资料库的原始文件可复用预处理结果；其他录音需要本机识别和时间定位。
3. 等待第一批稳定句子出现。长录音耗时较长，过程中可以查看「导入进度」，暂停处理或继续 / 重试译文。
4. 默认 Google 联网翻译仅发送英文文本。译文暂时失败时，保留已识别英文与时间标记，网络恢复后重试。
5. 如需要本机翻译，可主动选「离线翻译」，另下载约 1.12 GB 模型。离线翻译更耗时，默认不会自动下载这个模型。

识别固定 2 线程，保留分段间歇、播放优先和过热暂停。看到等待 / 冷却提示时，可先暂停导入、等设备冷却后继续。识别准确度受口音、背景音、多人同时说话和录音质量影响。

个人录音归档保存在设备内，切换资料后可恢复；重新导入同一份录音可复用已完成结果。首次识别需解码缓存，除原录音外约每分钟增加 1.92 MB PCM 数据，请预留空间。

## 后台收听

开始播放后可切换到其他应用或锁屏。系统媒体通知提供暂停 / 继续及上下句控制，耳机媒体键也可操作。Android 13+ 请允许通知权限；部分厂商设备还需允许后台运行。媒体卡片的位置和样式由系统决定。

来电、音频焦点变化或拔出耳机时会暂停。若播放失败，点页面的重试按钮，或在通知栏继续；无网络且录音尚未保存时，需要先恢复网络。

## 日志与反馈

入口：**我的 → 学习偏好 → 导出使用日志**，或练习页 **更多 → 使用日志**。

填写发生问题时的操作、资料名称、句子位置，选择是否附带识别文本，然后通过系统保存对话框导出 ZIP。默认不附带原文和译文；备注仍会保留。日志包含设备信息、处理耗时、温度读数、播放范围、错误等，不包含录音或模型。

使用日志是排查问题的材料，**不是学习记录备份**。公开上传前请检查文件名、备注、识别文本等内容；一般反馈可先只提供复现步骤。
