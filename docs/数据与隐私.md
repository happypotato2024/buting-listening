# 数据与隐私说明

适用版本：不听听力 2.0.0。

| 数据 / 操作 | 存放或发送位置 |
| --- | --- |
| 听力记录、签到、收藏、偏好、壁纸 | 本机应用存储 |
| 导入的个人音频、解码数据和识别结果 | 本机应用存储，录音不上传识别服务 |
| 默认联网翻译 | 将英语文本发送至 Google 翻译服务 |
| 可选本机翻译 | 模型下载后在本机处理文本 |
| 真题与目录加载 | 请求 GitHub 托管的资料仓库 |
| 识别 / 翻译模型下载 | 请求模型托管服务 Hugging Face 等配置来源 |
| 使用日志 | 本机滚动保存，由用户主动导出，不自动上报 |

第三方服务器正常处理下载和翻译请求时，会收到 IP、请求路径、时间等网络信息，按各服务自身政策处理。无登录不代表所有功能都不联网。

日志包含设备型号 / Android 版本、版本号、资料或句子标识、播放时间范围、进度、错误、耗时、可获取的温度 / 电量读数等。不导出录音、模型和完整音频帧索引。默认不附带原文和译文；主动选择附带文本、填写备注、个人文件名和错误信息仍可能包含个人内容，分享前请检查。

应用无需通讯录、定位权限。通过系统文件选择器获得用户选中的音频、壁纸和日志保存目标；媒体前台服务与通知权限用于后台播放。卸载 / 清除应用数据将删除本机学习记录和应用私有文件；单独导出的日志由用户自行管理。

本仓库 Issues 为公开页面。请勿直接提交私人录音、包含身份信息的截图或未经检查的完整日志。
